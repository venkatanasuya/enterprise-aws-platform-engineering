# Security

Do not add production or customer information to this repository.

Never commit:
- AWS account IDs
- access keys or secret keys
- GitHub/JFrog tokens
- passwords
- private certificates
- Terraform state
- `.tfvars` containing real values
- private IP addresses
- internal DNS names
- customer screenshots

All values in this repository use placeholders such as `<AWS_ACCOUNT_ID>`,
`<VPC_ID>`, `<SUBNET_ID>`, `<INTERNAL_DOMAIN>` and `<SECRET_NAME>`.
